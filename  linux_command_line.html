Principales commandes Python

Commande Description Exemple
input() Permet de demander une information à l'utilisateur. nom = input("Quel est ton nom ? ")
str() Convertit une valeur en chaîne de caractères (string). texte = str(25)
float() Convertit une valeur en nombre décimal. prix = float("12.5")
bool() Convertit une valeur en booléen : True ou False. resultat = bool(1)
print() Affiche une information dans la console. print("Bonjour")
int() Convertit une valeur en nombre entier. age = int("18")
len() Compte le nombre de caractères ou d'éléments. len("Bonjour")
